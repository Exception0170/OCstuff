# Changes

## release build v1.0.2010

First LTDE release for OpenOS, targeting Tier 2 graphics and at least 1 MB RAM.

- Window manager, taskbar, Start menu, notifications and settings.
- Buffered drawing for window moves, focus changes and scrolling.
- Explorer with mounted devices, file operations, recursive progress,
  Apply to all conflict handling, search, bookmarks and properties.
- Notepad, Command Prompt, Control Panel, Task Manager and My Computer.
- Calculator app and command, plus normal/bundled Redstone Control.
- Native command modules, aliases, Tab completion and output redirection.
- File associations, shared file colors, app configs and service management.
- TGL 0.9.5, tgl-ui and tgl-img included.
- Debug logging disabled by default; manual crash shortcut removed.
- Event-debugging app excluded from the release archive.
