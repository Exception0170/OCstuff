# Optional LTDE apps

These apps are developed separately from the LTDE system bundle. Copy a `.app`
folder into `/ltde/apps` to install it. Restart LTDE when registering a new file
association. App-specific requirements are in each bundle's README.

- [Image Viewer](imgview.app/README.md): actual-size viewing and scrolling of TMG images.
- [TPaint](tpaint.app/README.md): drawing and editing ordinary TMG images.
